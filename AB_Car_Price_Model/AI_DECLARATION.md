# AI 使用声明 / AI Assistance Declaration

本项目使用 AI 作为代码开发辅助工具，协助生成、修改、整理和调试代码，以及编写相关使用说明。AI 不作为本项目原始数据的提供者，也不作为研究结论的独立作者或背书方。

AI was used as a code-development assistant to help generate, modify, organize and debug code, and to prepare related usage documentation. AI is not the provider of the project's original data, nor an independent author or endorser of its research conclusions.

模型使用的原始车辆数据来自项目提供的爬取数据，不由 AI 虚构。`data/example.csv` 是用于演示输入格式的虚构示例，不属于真实车辆数据，也不用于正式模型训练或评估。

The original vehicle data used by the model comes from scraped data supplied for the project and was not fabricated by AI. `data/example.csv` contains fictional records demonstrating the input format; it is not real vehicle data and is not used for formal model training or evaluation.

模型指标应以实际执行代码得到的评估结果为依据。项目作者负责审核代码、确认数据使用权限、验证运行结果，并对最终提交内容负责；AI 生成的代码不替代这些审核与验证。

Model metrics must be based on evaluation results produced by actual code execution. The project author is responsible for reviewing the code, confirming data-use permissions, validating results and taking responsibility for the final submission. AI-generated code does not replace these reviews and checks.
